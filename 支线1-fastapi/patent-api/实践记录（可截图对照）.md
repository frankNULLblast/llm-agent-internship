# 实践记录（可截图对照）— FastAPI Day 1

> 每个场景给「敲什么命令 + 预期看到什么」，照着跑就能截图当证据。

## 场景 0：进入项目并激活统一 .venv

```powershell
Set-Location "$HOME\llm-agent-internship\fastapi-plus\patent-api"
..\..\.venv\Scripts\Activate.ps1
python --version
```

截图：命令行里 `(.venv)` 前缀 + Python 版本。

## 场景 1：安装依赖并验证版本

```powershell
python -m pip install "fastapi[standard-no-fastapi-cloud-cli]==0.139.0" "httpx2==2.5.0" "pytest==9.1.1" "openai==2.45.0"
python -c "import fastapi, httpx2, openai, pytest; print(fastapi.__version__, httpx2.__version__, openai.__version__, pytest.__version__)"
```

截图：第二行输出 `0.139.0 2.5.0 2.45.0 9.1.1`。

## 场景 2：启动开发服务器（保持运行）

```powershell
python -m fastapi dev main.py --host 127.0.0.1
```

截图：终端里 `Uvicorn running on http://127.0.0.1:8000`（这行是"服务起来了"的铁证）。

## 场景 3：命令行验证 /health 与 /openapi.json

新开一个终端（同样激活 .venv 并 cd 到项目）：

```powershell
(Invoke-RestMethod -Uri "http://127.0.0.1:8000/health") | ConvertTo-Json
(Invoke-WebRequest -Uri "http://127.0.0.1:8000/openapi.json").StatusCode
```

截图：第一个返回 `{"status":"ok","version":"0.1.0"}`；第二个返回 `200`。

## 场景 4：浏览器 / Swagger UI 验证

浏览器打开 `http://127.0.0.1:8000/docs` → 展开 `GET /health` → Try it out → Execute → 看到 `200` 和响应体。

截图：Swagger UI 页面，已展开 `/health` 且响应 `200`。

## 场景 5：pytest 测试（不需要服务运行）

先 `Ctrl+C` 停掉场景 2 的服务，再：

```powershell
python -m pytest -q
```

截图：终端显示 `1 passed`。

## 场景 6：挑战任务后看 /openapi.json 变化

改完 `main.py` 加 `summary`/`contact` 后：

```powershell
python -c "from main import app; import json; print(json.dumps(app.openapi()['info'], ensure_ascii=False, indent=2))"
```

截图：`info` 里出现 `summary` 和 `contact` 字段。
