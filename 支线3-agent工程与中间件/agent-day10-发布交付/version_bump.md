# Day 10 版本变更说明

## 变更内容

将 `main.py` 中的：

```python
APP_VERSION = "0.1.0"
```

改为：

```python
APP_VERSION = "0.2.0"
```

并把 `test_main.py` 中 `/health` 的版本期望从 `0.1.0` 改为 `0.2.0`，其余原 17 项契约断言**不改**。

## 为什么只改一处

- 功能在 Day 1–9 已冻结；Day 10 只做可复现交付，不引入新行为。
- 版本号是「本次实习交付」的标记，不影响任何业务状态或契约。
- 若为了通过版本升级而改了其他旧接口断言，应回退那些修改并找真实回归原因。

## 发布节奏（教材约束）

1. 更新版本、提交；
2. 从 Git 新克隆验证；
3. 运行 `ops/verify_agent_lab.sh`；
4. 全部通过后，再创建 `v0.2.0` annotated tag；
5. 不在测试失败或工作区未提交时打 tag。

> 真实执行与 tag 在培训 VM 的 `patent-agent-service`（Day 3 提交 e13000b 之上的演进）。
> 本仓库仅保留教材对应的设计与配置。
