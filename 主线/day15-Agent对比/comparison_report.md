## Day 5 固定 Python 工作流 vs 通用 Agent 的边界

Day 5 用 Python 脚本做字段抽取和规则校验：代码固定、逻辑确定、可测试、可重复，但只处理预定义格式，换一种票据就要改代码。

Day 15 用通用 Agent 做同样的事：Agent 能理解自然语言、适应格式变化、不需要改代码，但输出有随机性、需要人工验收、成本更高。

边界：格式固定、量大、要求确定性的场景用代码（Day 5 模式）；格式多变、量小、需要灵活理解的场景用 Agent（Day 15 模式）。生产中两者结合——Agent 做初步抽取，代码做规则校验和分流。
