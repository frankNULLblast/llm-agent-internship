# clear-done 挑战

> 一句话：加功能前先改 SPEC，再写代码。

## 任务
给待办 CLI 加 `clear-done`：删除所有已完成（done=true）的事项，打印清除数量。

## 做法（遵守协作纪律）
1. **先更新 SPEC.md**：把 `clear-done` 加进规格，定义行为（删除已完成、打印数量）
2. **再加代码**：
   - 注册子命令 `sub.add_parser("clear-done")`（无参数）
   - 处理分支：筛出 done 项 → 保留未完成的 → `save()` → 打印 `已清除 N 个已完成事项`
3. **验收**：
   - 加 3 个、done 两个 → `clear-done` 后只剩 1 个未完成 ✓
   - 空库跑 `clear-done` → `已清除 0 个已完成事项`，不报错 ✓

## 要点
- 挑战任务也要走"先改 SPEC、再写码、再验收"，和主流程一个纪律
- 空集合边界要单独验，避免除以零或越界
