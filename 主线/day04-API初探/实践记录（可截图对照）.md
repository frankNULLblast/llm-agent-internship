> 运行前必设（否则会 400）：`export DEEPSEEK_MODEL=deepseek-chat`（Git Bash）或 `set DEEPSEEK_MODEL=deepseek-chat`（cmd）。

## 场景 1：单轮问答 `chat_once.py`
**终端命令**
```
python chat_once.py "用一句话解释什么是 Token"
```
**喂给 DeepSeek 的 prompt（user 消息）**
> 用一句话解释什么是 Token

**模型返回（真实）**
> Token是AI处理文本时的最小基本单元，可以是一个词、一个汉字或一个标点符号，但具体拆法取决于模型使用的分词工具。

**附带用量**
```
[usage] input=18 output=32 total=50
退出码 exit=0
```


## 怎么截图最省事（推荐顺序）
1. **整屏终端窗口**：把上面任意一条命令 + 它的输出一起框进去，最直观证明「你跑过」。
2. **`usage.jsonl` 文件内容**：用 VS Code / Obsidian 打开，截图那几行 JSON，证明用量真的落盘了（不含密钥）。
3. **Obsidian 里这张对照笔记本身**：直接给老师看也行（输入、输出、用量都在）。
