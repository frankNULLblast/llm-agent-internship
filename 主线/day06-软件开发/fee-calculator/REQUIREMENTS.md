# 专利费用批次计算器需求

## 用户与目标

用户需要从一组虚构专利费用记录中得到按申请号、费用类型和全部记录汇总的 CNY 金额。

## 输入

命令：

python fee_calc.py fees.json -o summary.json

`fees.json` 必须是非空 JSON 数组。每条记录必须且只能包含：

- `patent_application_number`：非空字符串，符合本项目样例格式；
- `fee_type`：非空字符串；
- `amount_yuan`：大于 0、最多两位小数的十进制字符串。

## 输出

`summary.json` 包含固定字段：

- `currency`：固定为 `CNY`；
- `record_count`：记录数量；
- `by_application`：按申请号汇总，金额为两位小数字符串；
- `by_fee_type`：按费用类型汇总，金额为两位小数字符串；
- `total_yuan`：全部金额，两位小数字符串。

## 错误与安全

- 空数组、损坏 JSON、字段缺失或多余、错误类型、非法申请号和非法金额均返回退出码 1。
- 必须在全量验证和计算成功后才写输出；失败时不得创建或覆盖输出文件。
- 输入和输出路径不得相同，避免覆盖原始费用记录。
- 只读取命令行指定的一个输入文件，只写 `-o` 指定的一个输出文件。

## 非目标

- 不连接数据库、网络、模型 API 或真实专利系统。
- 不换算货币，不判断票据、专利或费用是否合法有效。
- 不提供图形界面、HTTP 服务或云部署。

## 固定验收

三条记录跨两个申请号和两个费用类型，总额必须为 `5600.50`。所有离线测试通过后，从新克隆目录运行同一命令并得到相同结果。
